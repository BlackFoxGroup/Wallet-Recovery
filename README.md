# Wallet Recovery

Wallet Recovery is intended to help people regain access to **their own** digital assets when they have forgotten some recovery phrase words. The complete application and activation tools are distributed separately through the official website.

This public repository contains project information and ethical-use guidance only. It does not include the paid application, recovery engine, activation-code generator, signing keys, or executable builds.

## Ethical use

- Use recovery tools only for wallets and assets you own, or where you have clear permission from the owner.
- Do not attempt to access another person's wallet, seed phrase, or private key.
- Keep recovery phrases, private keys, and generated recovery results private. Never send them to support or publish them in an issue.
- Follow applicable laws and respect the rights and privacy of others. Each user is responsible for their use of recovery tools and for protecting their own data.
- The project is intended to help legitimate owners recover access. Ethical principles must be respected throughout its use.

## Privacy

Recovery phrases and private keys should remain on the user's device. Optional balance checks may send public wallet addresses to the selected network provider. See the app's privacy guide for the precise behavior of the installed version.
